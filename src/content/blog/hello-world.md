첫 글이다. 왜 Medium을 떠나 GitHub 위에 블로그를 직접 지었는지부터 적는다.

## 왜 직접 지었나

Medium은 글을 **프로그래매틱하게 발행하기가 어렵다**. 에디터에 붙여넣고 서식을 다시 잡는 수작업이 매번 필요했다. 나는 글의 초안·정리·발행을 가능한 자동화하고 싶었고, 그러려면 발행 흐름이 이래야 했다:

```
마크다운(.md) 한 파일 작성  →  git commit  →  git push  →  자동 배포
```

GitHub Pages + 정적 사이트 생성기는 이걸 그대로 만족한다. 클릭도, CMS도, 잠금형 에디터도 없다.

## 구조

- **Astro**: 정적 사이트 생성기. 글은 `src/content/blog/*.md`, 디자인은 레이아웃·컴포넌트에 한 번만 박아둔다.
- **GitHub Actions**: `main`에 push하면 빌드해서 Pages에 배포.
- **콘텐츠와 코드의 분리**: 글을 쓸 때는 마크다운만 건드린다. 디자인 복잡도가 글쓰기 흐름으로 새지 않는다.

> 이 블로그의 원칙: 코드가 아니라 **결정과 교훈**을 남긴다. 무엇을 만들었나보다 왜 그렇게 결정했는지를 기록한다.
