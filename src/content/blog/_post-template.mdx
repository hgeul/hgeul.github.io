도입 문단은 그냥 **마크다운**으로 쓴다. 요점을 먼저 던지는 게 좋다(OREO).

## 1. 일반 텍스트와 코드

문단, **볼드**, `인라인 코드`, [링크](https://example.com) 모두 마크다운 그대로.

코드는 ``` 펜스로 쓴다. 이러면 중괄호 `{}` 도 안전하다:

```python
def search(q: str) -> list[dict]:
    return client.query({"vector": embed(q), "top_k": 5})
```

## 5. 다이어그램 (인라인 SVG)

SVG 는 `.svg-box` 로 감싸면 프레임 + 가로 스크롤이 붙는다.
색은 `currentColor` 를 쓰면 다크모드에서 자동으로 대비가 맞는다.

      <circle cx="180" cy="45" r="6" fill="currentColor" stroke="none" />

## 6. 강조 패널 / 표

<div class="card">
  중요한 결론이나 요약은 카드로 감싸 눈에 띄게.
</div>

표는 마크다운 표가 제일 편하다(사이트 테마로 렌더됨):

| 방식 | 기준 | 언제 |
|---|---|---|
| 코사인 유사도 | 각도 | 방향(의미)이 중요할 때 |
| 유클리드 거리 | 직선거리 | 절대 값 차이가 중요할 때 |
